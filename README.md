# 🎯 Sentiment Analysis of Flipkart Reviews

## 📌 Overview

Built an end-to-end **sentiment analysis system** to classify Flipkart product reviews as **positive or negative** and identify key customer pain points.

## 🛠️ Tech Stack

* Python
* Streamlit
* Scikit-learn
* NLTK
* Pandas, NumPy
* AWS EC2

---

## ⚙️ Features

* Predict sentiment from user input
* Real-time inference
* Clean and interactive UI

---

## 📊 Workflow

1. Text cleaning & preprocessing
2. TF-IDF feature extraction
3. Model training & evaluation (F1-score)
4. Deployment using Streamlit on AWS
